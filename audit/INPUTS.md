# Input provenance and coverage

All seven user-supplied drafts informed this rebuild. Originals are not republished
as authoritative teaching files. This avoids contradictory instructions and
unreviewed draft content being loaded as the active tutor protocol. The hashes
in [input-manifest.json](input-manifest.json) identify the exact supplied bytes.

| Input | Use in the rebuilt course |
|---|---|
| `Master_Teacher_and_Tutor_Handbook(1).docx` | tutor instructions, teaching, placement, progress, scenarios |
| `Python_Phase_1_Novice_Guide(1).md` | phase-1; tracker; beginner drills; misconceptions |
| `Python_Phase_2_Intermediate_Guide(1).md` | phase-2; CSV reporter; testing and packaging tasks |
| `Python_Phase_3_Expert_Study_Guide.md.docx` | phase-3; decorators, async pipeline, SQLite, selection |
| `Python_Phase_4_The_Researcher_Early_PhD(1).md` | phase-4; protocol; paired numerical experiment |
| `Python_Phase_5_The_Creator(1).md` | phase-5; evaluation; API contracts; benchmark; maintenance |
| `learning Phases.txt` | README; placement; assessment; corrected unsupported trajectory |

The source collection contains approximately 58,000 words. Headings, tables,
code blocks, and Word hyperlinks were extracted for intake. Repeated reading
lists and speculative schedules were condensed into a source map and explicit
lesson decisions. Specialist breadth is preserved as optional paths rather than
an encyclopedic requirement for every learner. Technical code and claims carried
forward have the bounded checks documented in [CLAIM_AUDIT.md](CLAIM_AUDIT.md).
This is a curated reconstruction, not a sentence-by-sentence certification of
all 58,000 original words or all linked resources.
