# Short repository practice

Choose a [repository lesson](../curriculum/github.md) when its task is useful.
These activities concern repository files and settings on github.com:

| Want to learn | Small task |
|---|---|
| Repository pages | Find Code, Issues, Pull requests, and the visibility label |
| Markdown | Create and preview a short documentation page |
| Licenses | Read the repository's license and notice requirements |
| `.gitignore` | Add an ignore rule on a practice branch |
| Branches and PRs | Propose a documentation edit and inspect its diff |
| Issues | Track one documentation improvement |
| Settings and access | Inspect the available role and ruleset controls |
| Releases | Draft notes for a documentation revision |

The lesson gives the needed buttons. There is no separate GitHub capstone.
For running, debugging, input, or saving your Python work, open
[workspace controls](BROWSER_WORKFLOW.md).
