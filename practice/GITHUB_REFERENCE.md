# GitHub quick reference

| Need | Where to go |
|---|---|
| Write and run Python | [Your Codespace](https://supreme-fishstick-5g5gxqwrgjrpcp777.github.dev/) |
| Run, input, stop, save, or sync buttons | [Workspace controls](BROWSER_WORKFLOW.md) |
| Repository settings, license, `.gitignore`, or collaboration | [Short repository lessons](../curriculum/github.md) |
| Current Python lesson | [Lesson index](../curriculum/INDEX.md) |

**Save** updates the file in the Codespace. **Run** executes Python there.
**Commit** records selected changes in its Git history. **Push** sends commits
to GitHub. **Pull** brings remote commits into the current branch.

A **branch** is a line of work; a **pull request** proposes merging changes.
An **issue** tracks a task. **Settings** configures the repository.
A **license** states reuse terms. **`.gitignore`** excludes matching untracked
files from ordinary staging and does not erase files already in history.
